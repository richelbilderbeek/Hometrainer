# History

Hometrainer started in 2009 as 'HomeTrainer',
a tool to practice self-made exercises.
It was renamed to 'Hometrainer 2' and grew into a complete suite
to create exercises, create tests, take tests,
score tests and create tests on paper.
That suite was written in C++ Builder and can be found at
[HometrainerVcl](https://github.com/richelbilderbeek/HometrainerVcl).

In 2011, a website version was created.
In 2013, Hometrainer was rewritten to have a command line version
and a Qt desktop version, yet these could only do exercises.

In 2026, all features of the Hometrainer 2 suite were added
to the Qt version, and the website version was removed.

Date       | Version | Description
-----------|---------|----------------------------------------------------------------
2009       | 0.9     | Initial version, called 'HomeTrainer'
2009-04-28 | 1.0     | Renamed 'HomeTrainer' to 'Hometrainer 2'
2010-01-28 | 1.8     | Complete suite: exercises, tests, grading and tests on paper
2011-10-16 | 2.0     | Initial website version, renamed 'Hometrainer 2' to 'Hometrainer'
2013-10-23 | 3.0     | Major architectural rewrite, added command line version
2026-11-24 | 4.0     | Ported the complete suite of version 1.8 to Qt, removed the website version

Tests created with Hometrainer 2 cannot be used by Hometrainer 4,
as the encryption has changed to give the same result on all computers.
Exercises can be used by all versions.
