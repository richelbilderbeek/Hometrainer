# Run Hometrainer

Run Hometrainer in your web browser, without installing anything.

- 'Load exercise' lets you pick one of the example exercises,
  or upload an exercise from your computer.
  Images of uploaded exercises cannot be shown
- Files you save (such as tests, test results and scores) are downloaded
- Files you load (such as tests and test results) are uploaded,
  one at a time
